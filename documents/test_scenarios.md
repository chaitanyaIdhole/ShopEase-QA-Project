# Test Scenarios

| Scenario ID | Feature | Scenario | Expected outcome |
|---|---|---|---|
| TS01 | Login | Login with valid credentials | Inventory page opens |
| TS02 | Login | Login with invalid password | Access denied with an error |
| TS03 | Cart | Add a product to cart | Selected product appears in cart |
| TS04 | Cart | Remove a product from cart | Selected product is removed |
| TS05 | Inventory | Sort by price low-to-high | Prices are in ascending order |
| TS06 | Checkout | Continue with required fields empty | Checkout is blocked with validation feedback |
| TS07 | Checkout | Complete checkout with valid demo data | Confirmation is displayed |
| TS08 | Inventory | Open product details | Correct product information is displayed |
